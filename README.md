# job-helper

The front end of an app to help with job applications and what not.

### List of Current workflow

1. Look for job on linkedin
2. read job description
3. apply to the job
   1. answer feeler questions
4. save info
   1. job description
   2. company name
   3. job title
   4. salary
   5. requirements
   6. date applied

### What I want to keep track of that I can’t

1. Resume version
2. application status
3. resume gaps/matches
4. online interviews
